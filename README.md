# lang-playground
Small programs, experiments and book exercises from learning languages and libraries.

## langs/

Language playgrounds.

| Folder | Year | What it is |
|---|---|---|
| [`c-playground/`](langs/c-playground/) | 2018 | Small C programs (fizzbuzz, pig latin, string reversal, temperature table) |
| [`js-playground/`](langs/js-playground/) | 2018 | Number exercises in JavaScript (factors, fibonacci, primes, pi) |
| [`java-playground/`](langs/java-playground/) | 2019 | Basic Java language exercises |
| [`go-playground/`](langs/go-playground/) | 2020 | Three versions of `echo` in Go |
| [`lua-playground/`](langs/lua-playground/) | 2020 | Small Lua exercises (factorial, palindrome, roman numerals) |
| [`python-playground/`](langs/python-playground/) | 2020 | Python basics (variables, strings, numbers, functions, modules, packages) |
| [`learn-python/`](langs/learn-python/) | 2022 | Python practice exercises |
