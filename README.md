# lang-playground
Short programs in different languages

## Imported repos

These folders were standalone repos, merged in with their full commit history.

| Folder | Year | What it is |
|---|---|---|
| `bluebird-practice/` | 2015 | Sample bluebird promise usage |
| `beej_c/` | 2018 | Completed exercises from Beej's guide to C |
| `fp-in-js/` | 2018 | Code samples from the book *Functional Programming in JavaScript* |
| `react-playground/` | 2018 | React experiments (epoch converter, library component) |
| `redis-retry-playground/` | 2018 | Testing redis retry behavior |
| `java-playground/` | 2019 | Basic Java language exercises |
| `lua-playground/` | 2020 | Small Lua exercises (factorial, palindrome, roman numerals) |
| `argon2-poc/` | 2021 | Comparing argon2, bcrypt, bcryptjs and scrypt hashing |
| `rmq-playground/` | 2021 | RabbitMQ exchange experiments |
| `learn_python/` | 2022 | Python practice exercises |
| `pytictactoe/` | 2022 | A textual game of tictactoe in Python |
| `python_clrs/` | 2023 | CLRS data structures in Python (linked list, stack, queue) |
| `python_exercises_for_programmers/` | 2023 | *Exercises for Programmers* solutions in Python |

Browse a folder's history with `git log -- <folder>/`.
